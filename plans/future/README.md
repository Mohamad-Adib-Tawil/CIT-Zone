# خطط الميزات اللاحقة

هذه ميزات مؤجلة عن النسخة الأولى. افتح ملف خطة مستقل لكل ميزة عند بدء تحديد متطلباتها، مع نموذج بيانات وصلاحيات وواجهات ومعايير قبول. لا تنشئ كوداً أو جداول مسبقاً لمجرد وجودها هنا.

توجد [خطة تحضيرية للمقالات وأسئلة الدورات](../features/12-future-community.md) تحدد قرارات المنتج وشروط التنفيذ والاختبار، ولا تعني بدء العمل عليها قبل حسم تلك القرارات.

| الميزة | الأسئلة التي يجب حسمها قبل التخطيط التفصيلي |
| --- | --- |
| المنشورات والمقالات والنصائح | من يكتب فعلياً؟ هل للأستاذ حساب أم تنشر الإدارة باسمه؟ من يراجع؟ هل ترتبط المقالة بمادة؟ كيف تُدار الصور والروابط؟ |
| أسئلة الدورات | هل السؤال خاص بالطالب أم ظاهر للجميع؟ من يجيب؟ هل توجد موافقة/تبليغ/إشعارات؟ كيف تُحمى بيانات الطالب؟ |
| أدوار الأساتذة | ما الصلاحيات المسموحة؟ هل يمكنهم الرفع والنشر مباشرة أم بعد مراجعة الإدارة؟ كيف يُسحب الوصول؟ |
| دورات متعددة للمادة | هل تتعايش أم تُؤرشف؟ كيف تنتقل الاستحقاقات والتقدم والتنزيلات بين الإصدارات؟ |

سجّل قرار إدخال كل ميزة في [سجل القرارات](../09-decisions.md)، ثم أضفها إلى [خطة المراحل](../07-roadmap.md).
