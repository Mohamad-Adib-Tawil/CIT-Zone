# دراسة نظام CIT Zone المختصرة

المواصفات المعتمدة بتاريخ 2026-10-08؛ مرجعها [المنتج](01-product.md) و[القرارات](09-decisions.md).

## الفكرة

منصة مستقلة لطلاب المعهد التقني للحاسوب في حلب. تطبيق Flutter للطالب ولوحة ويب منفصلة للإدارة، مع خادم API خاص. تخدم منصة واحدة، وتفصل قدرات DRM والهوية والتخزين لتسهيل إعادة استعمالها في تطبيقات تعليمية أخرى.

## المنهج والأدوار

سنتان وفصلان لكل سنة، قسم برمجيات وقسم شبكات، 28 مادة فريدة إجمالاً مع مواد مشتركة. الفصل ترشيح للطالب، وتبويب «كل المواد» يتيح جميع الأقسام والسنوات والتسجيل بأي مادة؛ يحتاج توزيع المواد ومشروع التخرج اعتماداً. الأدوار طالب وأدمن بصلاحية واحدة، والأستاذ كحساب مؤجل.

## الوظائف

- Google إلزامي وإكمال القسم والسنة والفصل؛ مواد إعادة اختيارية دون منح حق تلقائي.
- PDF مجاني للمادة ولكل جلسة، وأخبار وإعلانات مجانية بعد الدخول.
- أول فيديو لكل قائمة تشغيل معتمدة مجاني؛ بقية الفيديو باشتراك مادة أو فصل.
- فيديو DRM مع سرعة وتقديم/إرجاع، وتقييم خمس نجوم لكل درس.
- تنزيل PDF وفيديو مشفر داخل التطبيق؛ يمنع تصدير الفيديو، وتختبر حماية الشاشة دون ضمان منع التسريب.
- MCQ بتصحيح تلقائي وتمارين كود بمراجعة Gemini دون compiler.
- ملف الطالب: الحقوق والجهاز والتنزيلات ووقت أسبوعي والعلامات ومواد الإعادة وكشف PDF.
- إعلانات وإشعارات مبسطة وتذكير امتحان ودعم برسائل غير متزامنة.
- لوحة ويب للمحتوى والطلاب والدفع والأجهزة والتقويم والتمارين والإعلانات والدعم والعلامات.

## حالات الاستخدام

1. طالب يدخل بـGoogle؛ API يثبت الهوية والجهاز، ثم يستكمل الملف.
2. طالب يجد مادة في توصيات فصله أو كتالوج كل المواد ويقرأ PDF ويشاهد الفيديو الأول، ثم يشترك للوصول للباقي.
3. طالب يدفع عبر المسار المعتمد؛ الخادم يتحقق أو الإدارة تراجع إيصالاً، ثم يصدر الحق مرة واحدة.
4. طالب ينزل درساً مرخصاً ويشاهده دون اتصال ضمن مدة الرخصة.
5. طالب يحل MCQ أو يرسل كوداً للمراجعة ويرى التغذية الراجعة.
6. طالب يرى علاماته فقط ويولد كشفاً؛ لا يصل إلى الصورة الأصلية التي تحوي علامات الآخرين.
7. جهاز ثانٍ يُرفض مع زر الدعم؛ الإدارة تفوض النقل يدوياً وتبطل الجلسة القديمة.
8. إدارة ترفع محتوى وتراجعه وتنشره، أو ترفع صورة علامات وتصحح استخراج OCR ثم تعتمد النتائج.

## قواعد الاشتراك والبيانات

اشتراك المادة أو الفصل ينتهي بنهاية الفصل، مع استمرار مواد الرسوب/الحمل وفق سياسة إثبات ومدة ما زالت معلقة. تقويم الفصل في الخادم، ورخصة الأوفلاين لا تتجاوز الحق المعتمد. الدفع بأولوية ShamCash API إن توفر، وإلا QR وإيصال، وقسائم مطبوعة خيار محتمل.

العلامات مصدرها صور تدخل عبر لوحة الإدارة، بنسب عملي/نظري 30/70 أو 40/60 لكل مادة؛ لا يُعتمد OCR آلياً ولا توجد مزامنة مباشرة مع الجامعة. طريقة المطابقة وحد النجاح والتجميع والاحتفاظ تحتاج حسمًا.

## الحالة والقرارات المتبقية

الحالي معاينات Flutter وتهيئة Google؛ لا API أو لوحة ويب أو خدمات إنتاجية متصلة. يلزم المنهج والأسعار والاسترداد وتقويم الفصل واستثناء الرسوب ومزود DRM وسياسة OCR/Gemini وبيانات الاستضافة. البناء يلتزم Clean Architecture وSOLID وCubit والتفويض على الخادم والاختبارات ذات المعنى.
