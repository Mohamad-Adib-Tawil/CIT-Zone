# 07 — التنزيل المحمي والتشغيل دون إنترنت

**الهدف:** طالب مستحق ينزل درساً داخل مساحة التطبيق ويشغله دون اتصال حتى انتهاء رخصته، مع أقصى حماية عملية تدعمها الأجهزة والمزود؛ لا ضمان منع التسريب المطلق.

## شرط بدء قاطع

لا تبدأ تنفيذ إنتاجي حتى تثبت تجربة [خطة الوسائط](../05-media-offline.md) على Android وiOS الحقيقيين ودون MP4 واضح: بث DRM، رخصة offline، تشغيل بعد إغلاق التطبيق وفصل الإنترنت، انتهاء الرخصة، ونقل الجهاز. يلزم حسم D06/D08/D09 ومدة الاستحقاق D05. إن فشل المسار، أوقف هذه الميزة وارجع إلى القرار؛ لا تستبدلها بتشفير Dart محلي أو رابط MP4.

## حالات المجال

`notDownloaded → queued → downloading → paused → downloadedWithValidLicense → licenseExpiring/expired → renewing/deleting/failed`. حالة الملف غير حالة الرخصة وغير حالة استحقاق الخادم. واجهة التنزيل تعرض حجماً وجودة ومساحة متاحة وشبكة خلوية حسب السياسة. لا تبدأ تنزيلًا تلقائياً.

## تنفيذ الخادم

- `POST /lessons/{id}/offline-license` يفحص هوية الطالب والجهاز والاستحقاق والنشر وسقف التنزيل، ويربط الرخصة بأصل ومدة وسياسة استخدام محددة. تجديد الرخصة يعيد التحقق؛ جهاز ملغى لا يحصل على رخصة جديدة.
- احتفظ بسجل إصدار/تجديد/رفض دون حفظ مادة مفتاح حساسة، وحدد حدود معدل. ارجع رمزاً واضحاً عند انتهاء الحق أو تجاوز الحد أو عدم دعم الجهاز.
- لا يعد الخادم بحذف نسخة سبق ترخيصها وجهازها غير متصل؛ أقصى أثر مضمون هو عدم التجديد وانتهاء صلاحية الرخصة وفق مدتها.

## تنفيذ المنصة وFlutter

1. أنشئ جسر منصة محدد الأحداث (`enqueue/pause/resume/delete/status/playOffline/renewLicense`) وتغليف Android Media3/Widevine وiOS AVFoundation/FairPlay وفق تجربة المزود. لا تعبر بايتات الفيديو الواضحة إلى Dart.
2. خزّن الفهرس وملفات الوسائط المشفرة والرخصة وفق قواعد النظام داخل مساحة التطبيق الخاصة. عالج الملفات الناقصة، تحديث التطبيق، فقد مفتاح النظام، إزالة التطبيق، ونقص المساحة؛ لا تفترض أن وجود ملف يعني رخصة صالحة.
3. `DownloadCubit` يعرض قائمة وحالة كل درس وتقدم البايتات الموثوق، ويفصل network error عن license error وstorage error. اجعل الحذف idempotent، ودع المستخدم يمسح المساحة.
4. سياسة الواي فاي/الخلوي والجودة وعدد التنزيلات/التزامن تعتمد D09. لا تطلب إذن صور أو تخزين عام ما دام الملف في مساحة التطبيق الخاصة.
5. عند الخروج/نقل الجهاز احذف الفهرس والرخص/الملفات المحلية حيث تسمح المنصة، ثم اعتمد انتهاء الرخصة لحد عدم الاتصال الذي لا يمكن سحبه فوراً.

## مصفوفة قبول على الأجهزة

| التجربة | Android | iOS |
| --- | --- | --- |
| تنزيل، إغلاق التطبيق، فصل الشبكة، تشغيل | جهاز حقيقي | جهاز حقيقي |
| انتهاء الرخصة وتجديدها بعد اتصال | رفض ثم تجديد مصرح | رفض ثم تجديد مصرح |
| جهاز ملغى/حق منتهٍ | لا رخصة جديدة | لا رخصة جديدة |
| ملف ناقص/نقص مساحة/توقف شبكة | تعافٍ أو حذف آمن | تعافٍ أو حذف آمن |
| تفقد مساحة التطبيق/المعرض والسجلات | لا MP4 واضح/مفتاح ثابت | لا ملف واضح/مفتاح ثابت |

اكتب تقرير تجربة يذكر الطراز ونسخة النظام وإصدار SDK والمزود ونتائج الفشل. **لا يقبل** نجاح المحاكي وحده ولا لقطة شاشة لواجهة التنزيل دليلاً على حماية فعلية.
