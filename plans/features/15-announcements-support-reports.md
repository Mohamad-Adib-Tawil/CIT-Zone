# 15 — الإعلانات والإشعارات والدعم والوقت الأسبوعي

اعتماد 2026-10-08، مرتبط بالهوية والنطاق الأكاديمي والتقويم. قرارات D22 للخصوصية والاحتفاظ والمقاييس والقنوات، D23 لتواريخ الفصول. المواد المجانية متاحة بعد الدخول دون قيد قسم؛ جمهور الإعلانات والتذكيرات يحدد مستقلاً لترشيح ما يلائم المسار، ولا يوجد دور أستاذ جديد.

## الإعلانات والإشعارات

الإدارة تعكس أخبار/إعلانات الجهة الرسمية مع مرجع وتاريخ ونطاق قسم وفصل وحالة نشر وتصحيح. لا يُخترع مصدر scraping أو تكامل رسمي. لوحة ويب لتأليف إعلان وتحديد جمهوره ومعاينة قالب أو قالبين بسيطين. تذكير الامتحان يُفعّل يدوياً، ومواد الإعادة تُذكر في الفصل القادم من حالة معتمدة لا من اختيار الطالب فقط.

`Announcement`, `Notification`, `Delivery`, `ExamReminder`، مع نسخة ومفتاح منع تكرار وسجل. API للقراءة وحالة الاطلاع؛ إرسال push إن اعتمد ضمن النظام يحتاج مزوداً وإعداد Android/iOS وأذونات وتسجيل token وإزالته عند الخروج. لا تحتوي إشعارات شاشة القفل على علامة أو بيانات حساسة. تعطل التوصيل لا ينشئ الرسالة مرات متعددة، ورابطها يعيد التحقق من الصلاحية.

## دعم غير متزامن

`SupportThread`, `SupportMessage`, `DeviceTransferCase`؛ طالب يرى محادثاته فقط والأدمن يعالج الرسائل. حالات إرسال/فشل/إعادة محاولة/مرسل، مع idempotency وترقيم وترتيب ثابت وتحديث قابل للإعادة. لا وعد برد لحظي أو مهلة لم يعتمدها المنتج. أنواع المرفقات وحجمها تحتاج قراراً إن أضيفت.

تعارض الجهاز لا يمنح جلسة محتوى على الجهاز الجديد. زر الدعم يحتاج قناة مقيدة بعد إثبات Google أو قناة خارجية معتمدة؛ تُحسم كيفية بدء الطلب قبل session في D22. لا يُحجب مسار الدعم بقيد الجهاز ولا يستخدم لتجاوز القيد. تفويض النقل إداري يدوي، ثم إبطال الجلسات القديمة والتدقيق؛ لا نقل تلقائي بالنقر.

## وقت أسبوعي

يفصل وقت الواجهة النشطة عن وقت المشاهدة؛ تعريف مدة البقاء والمنطقة الزمنية وبداية الأسبوع D22. لا تُحتسب الخلفية كتعلم، ولا يجمع التطبيق كل أحداث اللمس. نموذج جلسات استخدام مع تجميع خادم، دفعات محدودة ومنع التكرار عند الأوفلاين، وحدود ومعالجة تغير الساعة. بيانات قياس الاستخدام لا تثبت استحقاقاً أو علامة ولا يُدعى أنها وقت تعلم مضمون.

## العقود والاختبارات

مقترحات `/announcements`, `/me/notifications`, `/support/threads`, `/me/activity-summary` ومسارات كتابة إدارية، تثبت بعد القرار. اختبر عزل محادثة ورفض رابط إعلان غير مسموح، رسائل مكررة وإرسال متزامن، token قديم بعد تغيير الحساب، رفض إشعارات النظام، تذكير موعد تغير، تغير التوقيت وأسبوع عابر وفترات أوفلاين. RTL وقارئ شاشة ونص طويل وتصفح لوحة الويب بالجوال، وحالات فشل جزئي لا تمحو اسم الطالب أو باقي ملفه.
