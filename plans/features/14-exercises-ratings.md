# 14 — التمارين وتقييم الدروس

نطاق معتمد بتاريخ 2026-10-08: MCQ وتصحيح تلقائي، وتمارين كود يراجعها Gemini LLM API دون compiler، وتقييم خمس نجوم لكل فيديو/درس. سياسة وصول التمارين مجانية/مدفوعة لا تزال D22، ولا تستنتج من مجانية PDF.

## MCQ

الإدارة تنشئ سؤالاً وخيارات ومفتاح جواب وشرحاً وحالة نشر ونسخة. الطالب لا يستلم مفتاح التصحيح قبل التقديم. API يفوض سياسة وصول التمارين والنشر دون قيد القسم، يسجل محاولة بمعرف منع تكرار ويحسب النتيجة على الخادم. تحديد عدد المحاولات وإظهار الحل والتقييم النهائي يحتاج قراراً. الاختبارات: جواب غير صالح، سؤال غير منشور، نسخة تغيرت، محاولة مكررة، ورفض وصول غير مخول وفق سياسة التمرين دون قيد القسم.

## مراجعة الكود عبر Gemini

`Exercise`, `ExerciseVersion`, `Submission`, `ReviewJob`, `ReviewResult` نماذج منفصلة. معايير وتعليمات تمرين محفوظة على الخادم؛ مفتاح Gemini في مخزن الأسرار ولا يوجد SDK بمفتاح خاص في Flutter.

يُرسل الكود كنص غير موثوق، دون تشغيله أو استخدام أدوات من تعليماته. prompt ومعايير ونسخة نموذج قابلة للتتبع، استجابة منظمة: نتيجة مقترحة تتحقق تعليمياً من صحة الحل وفق معايير التمرين، ملاحظات تفصيلية، نطاق سطر/عمود عند إمكان تحديده، وعدم يقين. يتحقق الخادم من schema وحدود الأسطر؛ لا يختلق موقع خطأ حين لا يعرفه. المخرجات تعليمية وقد تخطئ ولا تعادل تنفيذ الاختبارات أو ضمان الصحة.

قرارات D22: لغات التمرين، حجم الإدخال، خصوصية وموافقة إرسال الكود للمزود واحتفاظه، حد محاولات وتكلفة ومهلة ومراجعة بشرية للاعتراض. حالات queued/processing/reviewed/failed/rate_limited. مفاتيح منع تكرار وميزانية خادم تمنع فواتير مكررة بسبب ضغط الزر أو إعادة اتصال. لا رفع ملفات أو إرسال بيانات شخصية ضمن prompt تلقائياً.

الاختبارات: حلول صحيحة وخاطئة معروفة وحلول بديلة، نص يخدع التعليمات، استجابة JSON تالفة، أسطر خارج المجال، توقف المزود وتأخره، طلبان متزامنان، وتجاوز الحصة. لا تعتمد جودة المراجعة على demo واحد.

## تقييم الدرس

قيمة صحيحة 1–5، درس منشور ضمن النطاق المسموح، سياسة أهلية المشاهد وتعديل/حذف التقييم D22. قيد تقييم واحد لكل طالب ودرس مع تحديث آمن وتدقيق مناسب. تعرض المتوسط وعدد التقييمات من الخادم، وحالة لا تقييمات؛ لا ينشر اسم الطالب تلقائياً. اختبر قيم صفر/ستة، درس غير موجود/غير منشور، تحديث متزامن وتكرار.

## التنفيذ والقبول

API مقترح `/exercises`, `/submissions`, `/review-jobs`, `/lessons/{id}/ratings` بعد OpenAPI. Flutter بميزات exercises/lesson_ratings وCubits منفصلة، ولوحة ويب للمحتوى والمراجعة والتكلفة. تقاس جودة تغذية LLM الراجعة وتكلفتها على مجموعة اختبار، مع قرار قبول واضح قبل الإطلاق. لا تخلط درجات التمارين بالعلامات الرسمية المستوردة.
