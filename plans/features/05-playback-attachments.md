# 05 — تشغيل الفيديو والمرفقات

## تحديث النطاق 2026-10-08

هذا الاعتماد هو المرجع عند قراءة التفاصيل أدناه؛ تفاصيل التشغيل المعلقة في سجل القرارات لا تُستنتج من أمثلة العقود السابقة.

يُمنع تصدير الفيديو، ويُسمح بتنزيل داخلي برخصة DRM بعد التجربة؛ لا منع تنزيل مطلق. منع لقطة/تسجيل الشاشة يُختبر وفق كل منصة وجهاز دون ضمان. المشغل يدعم سرعة وتسريع/تبطيء وتقديم/إرجاع حسب المزود المختبر. أول فيديو مجاني بعد Google دون قيد قسم الحساب؛ PDF كامل/جلسة مجاني بعد الدخول لكل المواد المنشورة دون اشتراك فيديو. تفويض المرفق يقوم على نوعه والنشر، لا بمجرد استحقاق الدرس المدفوع. تُختبر حالات PDF مجاني مع فيديو مقفل، ومادة من قسم آخر متاحة، وفشل رخصة/تسجيل شاشة ودعم المشغل.

**الهدف:** تشغيل معاينة الدرس الأول والدروس المستحقة بجودة متكيفة، وفتح مرفقات مسموحة، مع تفويض مستقل لكل طلب. هذه الخطة للبث عبر الشبكة؛ التنزيل في [07](07-offline-downloads.md).

## بوابة قرار

اقرأ [خطة الوسائط](../05-media-offline.md) وD08/D12/D13. اختبر مزود الفيديو/DRM على Android وiOS قبل تثبيت SDK أو نموذج الرخص. لا يعتبر رابط موقّع وحده تحقيقاً لمطلب DRM للمحتوى المدفوع.

## حدود الثقة والعقود

- الإدارة ترفع الأصل عبر تذكرة قصيرة العمر صادرة من الخادم؛ webhook موثوق يحدّث `MediaAsset` من `uploading` إلى `processing/ready/failed`. إشعار العميل بنهاية الرفع لا ينشر الفيديو.
- `POST /lessons/{id}/playback` يتحقق من جلسة الطالب والجهاز والمنشور والاستحقاق، أو الدرس الأول المجاني بعد فحص النشر، ويرجع تفويضاً قصير العمر مخصصاً للأصل. خادم الترخيص يكرر التحقق اللازم؛ لا تكفي حراسة route Flutter.
- `GET /attachments/{id}/access` يتحقق من الهوية والنشر وسياسة نوع المرفق، ويرجع تدفقاً أو رابطاً قصير العمر. `Attachment.visibility` قرار مستقل؛ PDF مجاني دون اشتراك فيديو؛ غير PDF لا يصبح مجانياً تلقائياً.
- صنف أخطاء `NOT_ENTITLED`, `SESSION_EXPIRED`, `MEDIA_PROCESSING`, `MEDIA_FAILED`, `DRM_UNSUPPORTED`, `LICENSE_DENIED`, `ATTACHMENT_UNAVAILABLE` في العقد النهائي. لا تعرض روابط التخزين أو توقيعاتها في logs.

## تنفيذ Flutter والمنصات

1. صمم `PlaybackSession` و`PlaybackRepository` بعيداً عن Widget. `PlaybackCubit` يتعامل مع requesting authorization، initializing player، playing/paused/buffering، ended، failure، حق انتهى أثناء المشاهدة. لا يعيد طلب تفويض عند كل `build`.
2. اربط المشغل الأصلي المناسب بالمزود المعتمد عبر واجهة منصة صغيرة. نفذ تنظيف الموارد عند تغيير الدرس، مغادرة الصفحة، خلفية التطبيق، وسحب الجلسة. اختبر العودة بعد انقطاع الشبكة، وانتقال الجودة، والصوت/الشاشة وفق سياسة المنصة.
3. إذا اعتمد حفظ التقدم D13، أرسل تقدم مشاهدة بمعدل محدود ونقطة استئناف مدققة؛ عالج تعارض تقدم جهاز سابق بعد نقل الجهاز. لا تعتبر cache المحلي سجلاً نهائياً.
4. للمرفقات: اعرض قائمة النوع والحجم والخصوصية، وفتح PDF/الصورة داخل مسار مضبوط. عند السماح بتنزيل مرفق، اشرح أنه ملف يمكن نسخه؛ لا تطبق وعد حماية الفيديو عليه. امنع path traversal ومحتوى/نوع ملف غير معتمدين في الخادم.
5. أضف تسميات وصول لعناصر المشغل، ورسائل واضحة عند عدم دعم DRM أو فشل الترخيص، وزر إعادة محاولة عندما يكون آمناً.

## ملفات وحدات مقترحة

`features/playback/{domain,data,presentation}`؛ `features/attachments/...` إن اختلفت صلاحياتها ودورة حياتها؛ `core/platform/media_bridge` للعقد الأصلي فقط. ملفات Android/iOS تعتمد على SDK المختار ولا تُنسخ إعدادات عامة من مثال قبل تجربتها.

## تحقق إلزامي

| حالة | ما يجب إثباته |
| --- | --- |
| درس مجاني وفق D03 | تفويض معاينة فقط للأصل الصحيح |
| درس مدفوع بلا حق | لا URL ولا رخصة ولا مرفق خاص |
| حق منتهٍ/جهاز ملغى | فشل التشغيل والترخيص الجديد |
| وسيط `processing/failed` | رسالة مناسبة بلا محاولة نشر أو تشغيل زائف |
| رفع غير مكتمل/webhook مزور | لا يتحول الأصل إلى `ready` |
| انقطاع/استئناف | مشغل يتعافى أو يوضح الفشل، بلا تسرب موارد |

اختبر العقد والخادم، ثم على أجهزة حقيقية للمشغل/DRM. **يقبل** عندما ينجح المسموح ويفشل الممنوع تحت طلبات معدلة، وتبقى أسرار الفيديو والمرفقات خارج التطبيق وسجلاته.
