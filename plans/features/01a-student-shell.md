# 01أ — واجهة الطالب الرئيسية والتنقل

**الهدف:** واجهة دخول واضحة تقود الطالب إلى المنهج ودوراته وتنزيلاته وملفه، وتحافظ على حالة التنقل حين يذهب إلى درس ويعود. هذه طبقة تجربة فوق ميزات [المنهج](03-curriculum-catalog.md)، [الاستحقاق](06-entitlements.md)، [التنزيل](07-offline-downloads.md)، و[الملف](08-profile-support.md)، وليست مصدراً جديداً للبيانات أو التفويض.

## قرارات قبل تثبيت المسارات

D03 سياسة الزائر، D11 موضع لوحة الإدارة، D16 الهوية النهائية. لا تعرض «دوراتي» كأنها حق زائر، ولا تسمح بالتنقل إلى الإدارة لأن route اسمه معروف. بعد تسجيل Google، توجّه من نتيجة `/me` ودور الخادم؛ حافظ على مقصد الطالب إذا كان مسموحاً.

## خريطة تنقل مقترحة قابلة للمراجعة

```text
استقبال/زائر أو استعادة جلسة
├─ الرئيسية: متابعة آخر درس، مواد حسب مساري، حالة وصول مختصرة
├─ المنهج: قسم ← سنة ← فصل ← مادة ← دورة ← درس
├─ دوراتي: الحقوق الفعالة/المنتهية ← الدورة
├─ التنزيلات: درس محمل ← تشغيل دون اتصال
└─ الملف: الحساب، الجهاز، طلب نقل، إعدادات، خروج

إدارة (دور خادم فقط) → AdminShell مستقل عن تنقل الطالب
```

على الهاتف اجعل الوجهات العليا قليلة وواضحة؛ على لوحي استخدم تنقلاً جانبياً عند اتساع المساحة. إذا ازدحمت القائمة، ضم الوجهات الثانوية تحت «المزيد» دون إخفاء حالة الحقوق/التنزيلات. لا تثبت أسماء Routes النهائية قبل قرار D11.

## بيانات الرئيسية وحالاتها

- «متابعة التعلم» من آخر تقدم معتمد وفق D13، وإلا تعرض «ابدأ من المنهج» دون اختلاق درس شاهده الطالب.
- «مساري» يعرض القسم/السنة/الفصل كمرشح عرض يختاره الطالب؛ لا يغير استحقاقه. المواد المنشورة من API المنهج، والدورات التي يملكها من API الاستحقاقات.
- حالة التنزيل محلية ومقيدة بالرخصة؛ لا تعرض «متاح دون إنترنت» لمجرد اكتمال بايتات الملف.
- اجعل كل بطاقة تحتفظ بحالتها: جزء فاشل يوضح الخطأ ولا يمحو الأقسام الأخرى ولا يتحول إلى صفر. عند عدم وجود حقوق، رسالة قصيرة تقود للمنهج.
- حالات الاستقبال: أول فتح، استعادة جلسة، لا شبكة، جلسة انتهت، تعارض جهاز، دور إدارة. لا تعرض بيانات مستخدم سابق أثناء تغيير الحساب.

## هندسة وتنفيذ

`StudentShell` يملك التبويبات وحالة الوجهة والعودة؛ Cubit أو حالة تنقل مخصصة للبيانات المشتركة فقط. كل شاشة تملك Cubit طلباتها؛ لا تنشئ Cubit واحداً لكل الطالب. cache عام للكتالوج إن اعتُمد مستقل عن cache الحقوق الحساسة؛ امسح بيانات الحساب عند الخروج. دعم deep link إلى مادة/درس يمر عبر تحقق جلسة/حق ثم يفتح العنصر أو يشرح سبب الرفض.

## اختبار وقبول

اختبر تبديل التبويبات والعودة مع المرشح والتمرير، ضياع الشبكة جزئياً، خروج وتبديل مستخدم، فتح رابط درس خاص بلا حق، مقاسات 320/360/600/1024dp، الوضعين الفاتح والداكن، RTL وتكبير النص وقارئ الشاشة. **يقبل** عندما يصل الطالب إلى مادة منشورة خلال خطوات واضحة، لا يفقد موضعه عند الرجوع، ولا يرى حقاً أو بيانات من حساب سابق، وتبقى الإدارة خلف دور الخادم.
