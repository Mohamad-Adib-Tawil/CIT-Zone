# 05 — حالة تنفيذ لوحة الإدارة

> مرجع تصميم/تنفيذ Flutter بتاريخ سبتمبر 2026. في 2026-10-08 اعتمدت لوحة **ويب مستقلة**، وأُلغي نطاق الإدارة داخل تطبيق الطالب للإنتاج. اقرأ [نطاق لوحة الويب](README.md) و[التسليم الجديد](04-delivery.md) أولاً؛ أمثلة Widgets/Cubits والاختبارات الأصلية لا تعني اختيار Flutter Web أو اكتمال لوحة الويب. الوظائف والشاشات الإضافية في الفهرس الجديد جزء من النطاق المعتمد.

**التاريخ:** 2026-09-26. **المرحلة الحالية:** معاينة تفاعلية للواجهة داخل Flutter في وضع التطوير.

## ما يعمل الآن

- واجهة عربية RTL بتصميم Material 3 ووضعين فاتح وداكن، مع تنقل سفلي للهاتف وجانبي للمساحات الواسعة.
- الرئيسية: مؤشرات الدورات والمسودات والوسائط وطلبات الأجهزة، المهام العاجلة، إجراءات سريعة، وسجل نشاط مختصر.
- المحتوى: تبويبات الدورات والمنهج والوسائط، البحث والتصفية حسب القسم، تفاصيل الدورة والدروس والمرفقات، ونموذجا معاينة لإنشاء دورة وإضافة بيانات درس ومرفقات اسمية.
- الطلاب: البحث، تفاصيل الحساب والجهاز والاستحقاقات، ونموذج معاينة لمنح وصول مع مدة وسبب.
- طلبات نقل الأجهزة: القائمة والتفاصيل ومعاينة أثر القبول والرفض؛ وسجل إجراءات للقراءة وإعدادات معلوماتية.
- حالات التحميل والخطأ وإعادة المحاولة والفراغ حيث تنطبق، مع `Cubit` ومستودع بيانات منفصل عن الواجهة.
- بيانات العرض موجودة في `DemoAdminRepository` وتُحمّل **في وضع التطوير فقط** من شاشة الاستقبال. نسخة الإنتاج لا تعرض لوحة الإدارة حتى يتوفر تحقق الهوية والصلاحيات من الخادم.

## الحد الحالي

هذه معاينة تصميم قابلة للنقر، وليست لوحة إدارة تشغيلية. إنشاء دورة، منح استحقاق، قبول/رفض نقل جهاز، رفع وسيط، النشر، وتعديل الإعدادات **لا ترسل طلبات ولا تحفظ بيانات**. لا توجد API أو خدمة هوية متصلة بالمشروع حتى الآن. عينات المواد والطلاب أسماء تجريبية وليست المنهج المعتمد.

## الربط المطلوب بخادم API خاص

1. حسم `D07` المتبقي: تشغيل الخادم وقاعدة البيانات والاستضافة والجلسات. استخدم عقد OpenAPI بإصدارات وأخطاء موحدة قبل تنفيذ العميل.
2. بعد تجهيز Google Sign-In في العميل، يلزم التحقق من رمز Google في الخادم، ثم جلسة آمنة ودور إدارة يأتيان من الخادم فقط. لا تمنح الإدارة من جهاز العميل.
3. استبدال `DemoAdminRepository` بمستودع API خلف `AdminRepository`، مع نماذج نقل منفصلة، ترقيم وبحث على الخادم للقوائم الكبيرة، ونتائج جزئية للمؤشرات. لا تستخدم تجميع القوائم المحلية لحساب مؤشرات الإنتاج.
4. لكل إجراء كتابة: عقد طلب ونتيجة صريحان، تحقق صلاحيات وقيود المجال على الخادم، مفتاح منع التكرار للإجراءات الحساسة، رقم نسخة للتعارض، وسجل تدقيق غير قابل للتعديل من التطبيق.
5. ربط محرر الدورة بخدمة الوسائط وفحص جاهزية النشر على الخادم؛ لا يُنشر محتوى إذا لم يصبح فيديو الدرس الأول جاهزاً وموسوماً للمعاينة المجانية.
6. إضافة اختبارات عقد API، التفويض، حالات الفشل والتعارض، واختبارات أجهزة Android/iOS قبل اعتبار اللوحة قابلة للإطلاق.

راجع [خطة الإدارة وعقود الخدمات](../06-admin-api.md) و[مراحل التسليم](04-delivery.md). لا تفعّل الإجراءات من الواجهة بمجرد توفر عنوان للخادم؛ يلزم اكتمال شروط الصلاحيات والتدقيق وسلامة الوسائط.

## التحقق المنجز

نجح `fvm flutter analyze` و`fvm flutter test` على واجهة الهاتف والتنقل والمحرر بعرض `320dp` والتنقل الجانبي بعرض `1024dp` وحالة فشل تحميل البيانات. يلزم استكمال اختبار أحجام `360/600dp` وتكبير الخط والوصول على الأجهزة قبل الاعتماد النهائي.
