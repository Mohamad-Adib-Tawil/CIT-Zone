# 02 — مواصفات الشاشات والتنقل

> مرجع تصميم/تنفيذ Flutter بتاريخ سبتمبر 2026. في 2026-10-08 اعتمدت لوحة **ويب مستقلة**، وأُلغي نطاق الإدارة داخل تطبيق الطالب للإنتاج. اقرأ [نطاق لوحة الويب](README.md) و[التسليم الجديد](04-delivery.md) أولاً؛ أمثلة Widgets/Cubits والاختبارات الأصلية لا تعني اختيار Flutter Web أو اكتمال لوحة الويب. الوظائف والشاشات الإضافية في الفهرس الجديد جزء من النطاق المعتمد.

## هيكل التنقل

| المستوى الأول | شاشة أو تبويب داخلي | المسار المفاهيمي | فعل رئيسي |
| --- | --- | --- | --- |
| الرئيسية | ملخص الإدارة | `/admin` | فتح مهمة تحتاج إجراء |
| المحتوى | المنهج | `/admin/curriculum` | إضافة موضع مادة |
| المحتوى | المواد والدورات | `/admin/courses` | إنشاء دورة |
| المحتوى | مكتبة الوسائط | `/admin/media` | بدء رفع فيديو |
| الطلاب | قائمة الطلاب | `/admin/students` | البحث عن طالب |
| الطلاب | الاستحقاقات | `/admin/entitlements` | منح استحقاق وفق السياسة |
| الطلبات | نقل الأجهزة | `/admin/device-requests` | مراجعة طلب |
| المزيد | سجل الإجراءات | `/admin/audit` | تصفية السجل |
| المزيد | الملف والإعدادات | `/admin/settings` | تعديل تفضيلات العرض |

المسارات أسماء تخطيطية، وليست عقد URL أو تأكيداً لأداة توجيه محددة. تتشارك وجهات الهاتف واللوحي حالة الاختيار ومسار الرجوع؛ لا يفقد المستخدم مرشحات القائمة عند فتح عنصر ثم العودة.

## 1. الرئيسية

**الهدف:** إبراز ما يحتاج قراراً إدارياً اليوم. أعلى الصفحة: عنوان، اسم المسؤول أو صورته، آخر تحديث، وزر تحديث. في الهاتف تأتي «يحتاج إلى إجراء» بعد مؤشرات موجزة؛ في اللوحي تظهر بجانب العمليات السريعة. لا يملأ مخطط كبير المساحة الأولى.

| العنصر | تعريف البيانات | النقر |
| --- | --- | --- |
| دورات منشورة | عدد الدورات بالحالة `published` الآن | قائمة دورات مفلترة |
| مسودات الدورات | عدد الدورات بالحالة `draft` | قائمة المسودات |
| وسائط قيد المعالجة/فاشلة | عدّادان منفصلان أو بطاقة بحالتين؛ مصدرهما خدمة الوسائط | المكتبة مع المرشح المناسب |
| طلبات نقل معلقة | عدد الطلبات بالحالة `pending` | قائمة الطلبات المعلقة |
| قائمة تحتاج إجراء | فشل معالجة، دورة غير قابلة للنشر، طلب نقل معلق؛ مع حد عناصر وترتيب واضح | العنصر المعني |
| نشاط حديث | آخر عمليات الإدارة مع المسؤول والوقت، قراءة فقط | تفاصيل السجل |

كل رقم يعرض وقت أخذ اللقطة، وعند فشل خدمة جزئية تظهر «تعذر التحديث» لتلك البطاقة لا صفر. لا تضع مقياس «الطلاب النشطون» قبل تحديد معنى النشاط وفترته في API. الرسوم الزمنية إضافة لاحقة فقط عندما تتوفر بيانات وتعريفات مستقرة.

## 2. المنهج

**الهدف:** رؤية المواد في مواضعها الصحيحة دون نسخ الدورات. أعلى الصفحة مرشحات قسم ← سنة ← فصل، ثم قائمة مرتبة تعرض رمز المادة واسمها وموضعها والدورة المرتبطة وحالتها. في الهاتف بطاقات ذات إجراء واضح؛ في المساحة الواسعة صفوف قابلة للترتيب مع تفاصيل جانبية.

- الفعل الأساسي: «إضافة مادة إلى هذا الفصل» يختار `Subject` موجوداً أو ينشئ مادة جديدة وفق صلاحية الإدارة، ثم ينشئ `CurriculumPlacement`.
- يبيّن التصميم بوضوح أن ظهور المادة في قسمين هو **موضعان للمادة نفسها**؛ تظهر شارة «موجودة أيضاً في...» عند فتح تفاصيلها.
- قبل إزالة موضع، تُعرض الأماكن الأخرى وأثر الإزالة على اكتشاف الدورة، دون حذف الدورة أو استحقاقات الطلاب.
- حالة الفراغ تعطي تعليمات لإضافة أول موضع؛ حالة التكرار تشرح القسم والسنة والفصل الموجودين بالفعل.

## 3. المواد والدورات

**القائمة:** بحث بالاسم/الرمز، مرشح الحالة والقسم، عدد النتائج، ثم بطاقة أو صف: اسم المادة، الأستاذ الوصفي، عدد الدروس، حالة الدورة، آخر تعديل. لا تساوِ بين `Subject` و`Course` في التسمية.

**تفاصيل الدورة:** رأس ثابت فيه اسم المادة وشارة الحالة وإجراءات «معاينة»، «حفظ»، «نشر» حسب الحالة. أقسام: بيانات الدورة، الأستاذ الوصفي، الدروس، المرفقات الموزعة على الدروس، ظهور المادة في المنهج، وفحص جاهزية النشر. على الهاتف تظهر هذه الأقسام كعلامات أو قائمة داخلية بسيطة؛ في اللوحي يمكن عرض ملخص الدورة بجانب المحرر.

**محرر الدورة:** يحفظ مسودة على مراحل واضحة؛ الحقول المطلوبة موضحة؛ يعرض أخطاء الخادم بجانب الحقول؛ ينبه قبل المغادرة مع تغييرات غير محفوظة. لا يُعرض زر «نشر» نشطاً إن كانت شروط النشر غير مستوفاة. يوضح فحص الجاهزية سبب كل منع مع رابط إلى الدرس أو الوسيط المعني.

## 4. الدروس والوسائط والمرفقات

**قائمة الدروس داخل الدورة:** موضع الدرس، العنوان، شارة «الدرس التعريفي» على الأول فقط، حالة النشر، حالة الفيديو، عدد المرفقات. إعادة ترتيب الدروس تظهر أثر نقل الدرس الأول المجاني وتطلب تأكيداً إذا تغيرت سياسة الوصول.

**محرر الدرس:** عنوان، ملخص، موضع، فيديو، مرفقات، معاينة تشغيل للإدارة. لا تعرض بيانات مزود الفيديو السرية. تظهر حالة الوسيط منفصلة عن حالة الدرس: `uploading`، `processing`، `ready`، `failed`.

**مكتبة الوسائط:** قائمة رفع ومعالجة مع البحث والحالة ووقت الإنشاء وحجم الملف ومدته عند توفرها. يظهر تقدم الرفع عند وجوده، ثم حالة المعالجة من الخادم؛ لا يعتبر بلوغ الرفع 100% جاهزية للنشر. إعادة المحاولة واضحة وآمنة؛ لا تعد باستمرار الرفع بالخلفية قبل اختبار دعم المنصة.

**المرفقات:** تعرض نوع الملف وحجمه وخصوصيته والدرس المرتبط به. تؤكد الإدارة إن كان المرفق عاماً؛ الافتراض أن مرفق درس المعاينة خاص حتى يُوسم بوضوح.

## 5. الطلاب والاستحقاقات

**قائمة الطلاب:** بحث بمعرف/اسم/بريد وفق سياسة الخصوصية، مرشحات الحالة، وترقيم من الخادم. تعرض أقل معلومات شخصية لازمة: اسم الطالب، بريد مقنّع جزئياً إن أمكن، عدد استحقاقاته، وحالة جهازه. لا تعرض رموز الجلسات أو معرفات الجهاز الخام.

**تفاصيل الطالب:** تبويبات «الملف»، «الدورات»، «الجهاز»، «النشاط الإداري». تعرض تواريخ الاستحقاقات ومصدرها، مع فصل المنح اليدوي عن أي عملية شراء مستقبلية. الإجراءات الحساسة ضمن قائمة واضحة مع تأكيد وملاحظة سبب.

**الاستحقاقات:** قائمة عبر الطلاب والدورات مع مرشح المصدر والحالة والمدة. نموذج المنح يطلب الطالب والدورة وبداية/نهاية واضحة ومصدر المنح وسبباً إدارياً. يمنع التكرار أو التعارض وفق نتيجة الخادم؛ لا يقرر العميل وحده إمكانية المنح.

## 6. طلبات نقل الأجهزة

قائمة الطلبات بحالات `pending` و`approved` و`rejected` و`completed` أو الحالات المعتمدة في العقد النهائي. كل عنصر يعرض الطالب، وقت الطلب، مدة انتظاره، سبباً مختصراً إن كان مسموحاً، وقراراً مطلوباً. التفاصيل تعرض الجهاز الحالي والجديد بصيغة آمنة ومعلومات تحقق مناسبة دون كشف أسرار المفاتيح.

يُمنع زر النقل السريع من القائمة؛ القرار داخل التفاصيل بعد عرض أثره: إبطال جلسة الجهاز السابق، وعدم إمكان سحب رخصة أوفلاين قد صدرت فعلاً قبل انتهاء مدتها. تُسجل هوية المسؤول والسبب.

## 7. سجل الإجراءات

قراءة فقط. مرشحات بالمسؤول والنوع والفترة والكيان، مع ترقيم من الخادم. صف السجل: الفعل، الهدف، المسؤول، الوقت، النتيجة، ومعرف طلب مفيد للدعم. لا تعرض رموزاً أو روابط تشغيل أو حقولاً حساسة في الفرق قبل/بعد. شاشة التفاصيل تشرح ما تغير دون إتاحة تعديل السجل.

## 8. الملف والإعدادات

تعرض هوية المسؤول ودوره، إصدار التطبيق، آخر مزامنة، تسجيل خروج، تفضيل الوضع الداكن/الفاتح وفق سياسة العلامة، ومساعدة داخلية. لا تسمح بتغيير دور الإدارة من هذه الشاشة. إعدادات المنصة والموارد الحساسة تبقى خارج التطبيق حتى تُحدد سياسة تشغيلها.
