# لوحة إدارة CIT Zone — تطبيق ويب مستقل

اعتمد صاحب المنتج في 2026-10-08 لوحة ويب منفصلة ومتجاوبة مع الجوال بصلاحية أدمن واحدة. تقنية الويب لم تُحدد. Flutter الحالي معاينة تطوير مرجعية ولا يمثل لوحة الويب المنجزة؛ [حالة التنفيذ التاريخية](05-implementation-status.md).

## الملفات

- [نظام التصميم](01-design-system.md): RTL وألوان ومكونات واستجابة وإمكانية وصول؛ أمثلة Flutter تاريخية.
- [الشاشات](02-screen-specs.md): تفاصيل الإدارة القديمة مع نطاق الويب المعتمد في هذا الفهرس.
- [الرحلات](03-flows-and-states.md): التأكيد والتعارض والفشل والتدقيق، مع توسعات النطاق الجديدة أدناه.
- [التسليم والهجرة](04-delivery.md): تنفيذ ويب مستقل وبوابات قبول.

## خريطة الإدارة المعتمدة

- الرئيسية: مؤشرات موثوقة المصدر، ومدفوعات وطلبات جهاز واستخراج علامات تحتاج مراجعة.
- المنهج: الأقسام والمواد الفريدة والمواضع ونسخ المنهج والتقويم السنوي للفصول.
- المحتوى: دورات ودروس ووسائط وPDF كامل/جلسة، ومراجعة حقوق الملفات ونسخها ونشرها.
- الطلاب: ملف أكاديمي وهوية مطابقة نتائج وأجهزة وطلبات نقل يدوية واستحقاقات ومواد إعادة.
- الاشتراكات والدفع: باقات مادة/فصل، إيصالات ومراجعة وتسوية، وقسائم إذا اعتمدت.
- التمارين: MCQ وأجوبة محفوظة على الخادم، تعليمات كود ومعايير مراجعة Gemini ومراقبة التكلفة.
- الأخبار والإشعارات: مصادر وتواريخ ونشر وتذكير امتحان بقالب أو قالبين.
- الدعم: محادثات غير متزامنة وحالات الطلب وربط طلب النقل.
- العلامات: دفعات صور OCR، ربط الطلاب والمواد والفصل، مراجعة كل خطأ واعتماد وتصحيح وكشف PDF.
- التقارير: وقت أسبوعي وتعريف فترة ومقياس، وتقييمات الدروس دون كشف بيانات الطالب للآخرين.
- التدقيق والإعدادات: سجل قراءة فقط، ملف الأدمن، إعدادات عرض، أسرار مزودين على الخادم فقط.

## مواصفات الصفحات الجديدة

الإيصالات تعرض ملفاً خاصاً ومرجع طلب ومبلغاً وحالة وسبب قبول/رفض؛ زر الاعتماد لا ينفذ مرتين. العلامات تعرض الصورة للأدمن فقط، جدول استخراج قابل للمراجعة، أخطاء درجات ومطابقة غير مؤكدة ونسخة اعتماد؛ لا اعتماد حتى معالجة الأخطاء. التقويم يعرض أثر تغيير التاريخ على حقوق الطلاب قبل الحفظ. المحادثة تعرض تسلسلاً وترقيماً وحالة إرسال ولا تعد برد لحظي. التمارين تخفي مفتاح تصحيح MCQ وتعرض حالات LLM غير المتاحة بأمان. المؤشرات لا تتحول إلى صفر عند فشل مصدر.

النمط البصري السابق قابل للاستعمال بعد اعتماد D16؛ في الويب تُختبر الجداول والملفات ولوحة المفاتيح والروابط المباشرة وإعادة التحميل على حاسوب وجوال. كل فعل يخضع لتفويض ومعاملة خادم، حتى مع أدمن واحد.
