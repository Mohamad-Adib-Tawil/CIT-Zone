## تصور التجربة

لوحة عملية وسريعة تساعد المسؤول على الإجابة عن ثلاثة أسئلة فور فتحها: **ما الذي يحتاج تدخلاً الآن؟ ما حالة المحتوى؟ وكيف أصل إلى المهمة التالية؟** تظهر مؤشرات محددة المصدر والزمن، ثم قائمة مهام عاجلة وعمليات سريعة. لا تُستعمل رسوم بيانية لمجرد الزينة أو أرقام تجريبية في نسخة منشورة.

**اتجاه بصري مقترح قابل للمراجعة:** Material 3 بلمسة تعليمية تقنية؛ خلفية فاتحة هادئة، لون أزرق واضح للإجراء الأساسي، لون تركوازي محدود للتمييز، بطاقات مرتبة، مسافات مريحة، أيقونات مألوفة، ونصوص عربية مباشرة. لا يُعد هذا اعتماداً للشعار أو الخط النهائي.

## خريطة المعلومات

```text
الرئيسية
├─ مؤشرات المحتوى والطلبات
├─ يحتاج إلى إجراء
├─ عمليات سريعة
└─ النشاط الأخير

المحتوى
├─ المنهج: الأقسام ← السنوات ← الفصول ← مواضع المواد
├─ المواد والدورات
│  └─ تفاصيل الدورة: بياناتها ← الدروس ← المرفقات ← معاينة النشر
├─ الأساتذة التعريفيون (بيانات عرض فقط)
└─ مكتبة الوسائط وحالات الرفع

الطلاب
├─ قائمة الطلاب
│  └─ تفاصيل الطالب: الحساب ← الاستحقاقات ← الجهاز ← الإجراءات
└─ الاستحقاقات

الطلبات
└─ نقل الأجهزة وحالاتها

السجل والإعدادات
├─ سجل الإجراءات، قراءة فقط
├─ الملف الإداري
└─ إعدادات العرض المحلية
```

لا توجد واجهة أستاذ ولا قسم «مبيعات» في النسخة الأولى. تظهر إيرادات أو مدفوعات فقط بعد اعتماد آلية الاشتراك وتوافر بيانات موثوقة لها.

```text
هاتف، RTL                                  لوحي / مساحة واسعة، RTL

│ صباح الخير، إدارة المعهد      │           │ الرئيسية  │ العنوان + آخر تحديث + تحديث         │

│ دورة منشورة  │ مسودة         │           │ الطلبات   ├──────────────────┬──────────────────┤
├──────────────┼───────────────┤           │ السجل     │ يحتاج إلى إجراء │ عمليات سريعة     │

├──────────────────────────────┤           │          │                  │ النشاط الأخير    │
│ يحتاج إلى إجراء              │           └──────────┴──────────────────┴──────────────────┘
```

المخطط يحدد ترتيباً وظيفياً، لا قياسات نهائية. لا تُحجب قائمة الأخطاء المهمة خلف بطاقة رسم أو عدد كبير من المؤشرات.

## حدود المحتوى والتفويض

- لا تظهر اللوحة إلا بعد تأكيد دور الإدارة من الخادم. تخفي الواجهة الأفعال غير المسموحة لتحسين الوضوح، والخادم يرفضها مهما كانت حالة الواجهة.
- كل مؤشر يستمد تعريفه ونطاقه الزمني وصلاحيته من API. عند تعذر جلب جزء، تظهر حالة جزئية بدل عرض `0` مضلل.
- الإجراءات الحساسة، مثل منح الاستحقاق ونقل الجهاز والنشر، تحتاج ملخص أثر وتأكيداً وسجل تدقيق؛ تفاصيلها في [الرحلات والحالات](03-flows-and-states.md).
