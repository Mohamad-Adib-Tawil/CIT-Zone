# بطاقة مهمة F01 — أساس اتصال API مستقل عن تقنية الخادم

**الخطة:** `plans/features/01-foundation.md`، مع `plans/02-architecture.md` و`plans/08-quality.md`.

- **الهدف:** يستطيع العميل لاحقاً طلب API الخاص بعنوان بيئة محدد، ويتلقى نتيجة أو خطأ مصنفاً دون تسريب بيانات حساسة أو قبول HTTP غير آمن في staging/prod.
- **داخل النطاق:** إعداد `APP_ENV` و`API_BASE_URL`، عميل HTTP قابل للحقن، مهلة، إلغاء، معرّف طلب، حد لحجم JSON، وتحويل حالات HTTP إلى أخطاء ثابتة. لا يُعرض محتوى تجريبي في الإنتاج.
- **خارج النطاق:** إنشاء خادم، اختيار لغته أو قاعدة بياناته، تثبيت أسماء endpoints، جلسة/رمز تفويض، تجديد جلسة، أو فتح لوحة الإدارة في الإنتاج.
- **القرار:** D07 يحسم فقط أن الخادم API خاص بتاريخ 2026-09-26؛ التقنية والاستضافة والعقد النهائي معلقة. D11 تطبيق واحد مقترح ولم يُعتمد. هذا الأساس لا يقرر أياً منها.
- **الأدوار والرفض:** لا صلاحيات داخل هذا النقل؛ أي 401/403 يصنف للفصل الأعلى، ولا يحول الرد إلى وصول. لا يحق للعميل الحالي إرسال طلبات إدارة أو محتوى مدفوع.
- **الكيانات والقيود والتزامن:** `AppEnvironment` ثابتة وقت البناء؛ `ApiRequest/ApiResponse/ApiFailure` للنقل فقط؛ لا حالة مشتركة قابلة للتغيير ولا تخزين رموز. الإلغاء خاص بالطلب.
- **العقد:** لا endpoint منتج حتى تثبيت OpenAPI. النقل يقبل مساراً نسبياً داخل الأصل المهيأ، وJSON object للطلبات/الردود، ويقرأ `X-Request-ID` عند وجوده. أخطاء HTTP 401/403/409/429/5xx والأخطاء الشبكية والمهلة والإلغاء والرد غير الصالح تُحوّل إلى رموز داخلية. `requestId` يرسل كرأس ولا يتضمن بيانات مستخدم.
- **الحالات البصرية:** لا شاشة جديدة؛ طبقة العرض اللاحقة تترجم الخطأ إلى نص عربي. الوضع الحالي يبقي شاشة الترحيب والمعاينات كما هي.
- **الملفات:** `lib/app/app_environment.dart`، `lib/core/network/*`، اختبارات `test/core/network/*`، وثائق التنفيذ. لا تغييرات Android/iOS أو ترحيلات في هذه الشريحة.
- **الاختبارات:** عنوان dev المحلي ورفض HTTP البعيد/production، مسار يخرج من أصل API، استجابة JSON صحيحة/ناقصة/كبيرة، 401/403/409/429/5xx، مهلة وإلغاء، معرّف الطلب. ثم فحوص Flutter الإلزامية.
- **الأداء/المراقبة:** مهلة كلية وحجم رد محدود؛ لا logging للرؤوس أو المتن أو الرموز.
- **القبول:** لا طلب إلى عنوان غير مهيأ أو غير آمن في الإنتاج؛ يستطيع fake محلي اختبار النقل دون خادم المنتج؛ الفشل مصنف ولا يُعرض كنجاح؛ لا تتحول أي معاينة إلى ميزة إنتاجية.

## التهيئة

`APP_ENV` الافتراضي هو `development` في debug و`production` في release. `API_BASE_URL` فارغ حتى يحدد عنوان الخدمة. الاتصال الخارجي يتطلب HTTPS؛ HTTP المحلي (`localhost` أو `127.0.0.1` أو `::1`) مسموح في development لاختبارات النقل على المضيف، ولا يُعد إعداد Android/iOS للوصول إلى خادم محلي. عند إنشاء خادم التطوير للمحاكي، حدد إعداد الشبكة الأصلي المناسب في مهمة مستقلة؛ لا تفتح cleartext على كل عناوين الإنتاج.

مثال لقيم البناء بعد توفر خادم HTTPS:

```sh
fvm flutter run --dart-define=APP_ENV=staging --dart-define=API_BASE_URL=https://api.example.test/v1/
```

هذا مثال عنوان فقط؛ لا يوجد خادم CIT Zone على `example.test` ولا يتم استدعاؤه حالياً. لا تحتوي طبقة النقل على جلسات أو رموز Google أو منطق صلاحيات.
