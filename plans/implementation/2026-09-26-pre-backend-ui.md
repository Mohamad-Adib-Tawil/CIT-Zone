# بطاقة تنفيذ — واجهات ما قبل الخادم

- **الهدف:** بناء استقبال وتسجيل Google من جهة العميل، معاينة واجهة الطالب والملف الشخصي، والإبقاء على معاينة الإدارة قابلة للوصول في debug.
- **داخل النطاق:** هوية Google مؤقتة في الذاكرة، صفحات الطالب بنماذج محلية موسومة كتجريبية، تنقل متكيف، حالات تحميل/فراغ/خطأ، إعدادات Android/iOS الممكنة دون معرفات OAuth.
- **خارج النطاق:** جلسة تطبيق، منح دور، ربط جهاز، اشتراك، تشغيل/تنزيل فيديو، حفظ بيانات إدارية، أو نشر محتوى. لا تحل هوية Google محل تحقق الخادم.
- **القرارات:** D07 خادم API خاص؛ D01/D03/D04/D06/D08/D10/D11/D16 لم تُحسم بالكامل. معاينات debug فقط لحين الحسم.
- **الأدوار:** صفحة Google تستقبل هوية عرض فقط؛ دخول معاينة الطالب والإدارة متاح للتطوير فقط، وليس تفويضاً.
- **عقد API:** لا يوجد خادم حالياً. `GoogleIdentityGateway` يعيد الاسم/البريد/الصورة بعد تحقق SDK من وجود ID token، ويمسح الهوية عند الخروج؛ التبادل المستقبلي عبر `POST /auth/google/exchange` في خطة الهوية.
- **الحالات:** إعداد Google ناقص، جارٍ، إلغاء، فشل، هوية متاحة؛ معاينة طالب تحميل/فراغ/خطأ؛ عدم توفر بيانات الحقوق والتنزيلات.
- **الملفات:** `lib/app`، `lib/features/auth`، `lib/features/student`، إعدادات Android/iOS، `pubspec.yaml`، الاختبارات، README وحالة التنفيذ.
- **التحقق:** تحليل واختبارات Flutter، اختبارات Widget لهاتف ضيق/لوحي، بناء المنصات المتاحة، لا اختبار Google فعلي قبل معرفات OAuth وجهاز مسجل.
- **قبول الجزء المستقل:** الواجهات تعمل في debug، نسخة release لا تعرض بيانات demo أو لوحة إدارة، وتسجيل Google لا يمنح جلسة أو دوراً من العميل.
