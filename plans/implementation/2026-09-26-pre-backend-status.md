# حالة تنفيذ الواجهات قبل الخادم

**التاريخ:** 2026-09-26. هذا الملف يميّز ما يشتغل فعلاً عما لا يزال واجهة أو إعداداً ناقصاً.

## المنفذ

- شاشة استقبال عربية RTL تعرض مسار Google ومعاينتي الطالب والإدارة في debug فقط.
- تكامل `google_sign_in` الرسمي بنسخته 7.2.0: تهيئة مرة واحدة، اختيار حساب على Android/iOS بعد إعداد OAuth، فحص وجود ID token في الذاكرة، عرض الاسم والبريد في صفحة هوية Google، وخروج. لا تُحفظ الرموز ولا تُطبع ولا تُمنح أي صلاحية من العميل.
- محاولة استعادة حساب Google السابق عند بدء التطبيق بعد إعداد OAuth؛ في معاينة التطوير تظهر بيانات الهوية نفسها داخل صفحة الملف الشخصي دون ادعاء وجود حساب تطبيق.
- معاينة طالب ببيانات نموذجية منفصلة عن الواجهة: الرئيسية، المنهج مع بحث ومرشحات قسم/سنة/فصل، تفاصيل مادة ومواضعها ودروسها، «دوراتي»، التنزيلات، والملف الشخصي. التبويبات تحافظ على حالة القائمة أثناء التنقل.
- معاينة الإدارة السابقة مع نموذج إضافي لبيانات الدرس ومرفقاته الاسمية، بلا رفع أو حفظ.
- إعداد Android للإنترنت وإعداد iOS لإعادة توجيه Google عبر قيمة xcconfig محلية؛ [خطوات OAuth الدقيقة](google-oauth-setup.md).
- اختبارات Widgets وCubit تغطي الشاشة الصغيرة والتنقل والمنهج المشترك وحالات فشل التحميل/إلغاء Google ومحرر الدرس.
- أساس اتصال API مستقل عن تقنية الخادم: إعدادات بيئة، HTTPS خارج الاختبارات المحلية، مهلة وإلغاء وحد حجم JSON وتصنيف أخطاء، مع اختبارات خادم محلي. لم يُوصل بأي endpoint منتج بعد.
- معرّف Android/iOS أصبح `com.devmind.cit.learn`. Android release يطلب مفتاح رفع خاصاً خارج Git؛ debug يبني، وتوجد بوابة CI لبناء Android debug. لم يُقدَّم مفتاح توزيع حقيقي بعد.

## غير متاح حتى الآن

- لا توجد معرفات OAuth في المستودع؛ زر Google معطل إلى أن تُسجل تطبيقات Android/iOS/Web client في مشروع Google Cloud ثم تمرر قيم البناء.
- نجاح Google وحده يعرض **هوية مؤقتة**، لا تسجيل دخول إلى CIT Zone. خادم API الخاص لم يتحقق من الرمز ولم يصدر جلسة أو دوراً أو ربط جهاز.
- مواد المعاينة ليست المنهج الرسمي. لا اشتراكات أو تقدم مشاهدة أو تشغيل فيديو أو مرفقات حقيقية أو رخص أوفلاين؛ صفحاتها تعرض حالة فراغ/شرحاً واضحاً.
- لوحة الإدارة في debug لا تحفظ أي تعديل ولا تملك صلاحية فعلية؛ نسخة الإنتاج لا تعرض معاينتي الطالب والإدارة.

## الخطوة التالية المعتمدة على خدمات خارجية

أولاً إعداد OAuth وتجربة الحساب على Android/iOS فعليين. ثم تنفيذ خادم `POST /auth/google/exchange` مع تحقق Google، الجلسة وربط الجهاز والدور، وبعده API المنهج والاستحقاقات والإدارة. لا تُبدل معاينات debug بمحتوى إنتاج قبل حسم القرارات D01/D03/D04/D06/D08/D10/D11 ودخول الخدمات.
