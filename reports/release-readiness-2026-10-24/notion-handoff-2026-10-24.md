PDF الحقيقي وحفظه/مشاركته يتبعان نشر العلامات والحقوق من الخادم.

Firebase المقدم من المالك cit-learn-dc483 وباندل com.devmind.cit.learn للنظامين: Google وFCMv1 Enabled في فحص24 أكتوبر. JSON Android مطابق وWeb OAuth client يطابق افتراضي Dart؛ لا Firebase initialization/firebase_core/firebase_messaging بعد، وAPNs development/production key/certificate غير موجودة. المتبقي FlutterFCM وأذونات/قنوات/فتح الوجهة، iOS APNs والتوقيع لدى مالك Apple، وبصمات release/Play App Signing؛ android/key.properties غائب. Google Enabled لا يثبت نجاح release ولا يحسم Google ID token مقابل Firebase ID token.

الوسائط: لا مشغل أو أوفلاين DRM إنتاجي؛ يلزم مزود/عقود وتجربة أجهزة ثم تنفيذ Flutter دون MP4 واضح أو مفاتيح خدمة. قبل النشر: أجهزة API24/2GB وiOS15 وARM32/ARM64 عند الدعم، RTL/accessibility/لوحة مفاتيح/نص150% وشبكة ضعيفة وقياسات profile/release، حزم AAB/IPA موقعة وinternal testing/TestFlight وخصوصية/متاجر وروابط تحديث؛ لا نشر جاهز حالياً. جردFigma24 أكتوبر97إطاراً مع F02 مكرر80:113 و198:9601؛ يلزم تحديد المعتمد قبل التعديل البصري.

### BE-AUTH — الأولوية الأولى لتفعيل بقية التطبيق

نفّذ الناقص أو تحقق من الموجود ثم سلّم POST auth/google وauth/refresh وauth/logout وGET me/session-state تحت /api/v1 بحسب التنفيذ المعتمد. حدّد Google ID token أو Firebase ID token صراحة؛ مشروع Google/FCM المعتمد cit-learn-dc483 وpackage/bundle com.devmind.cit.learn. العميل يستخدم google_sign_in مباشرة؛ لا نفترض Firebase Auth token. تحقق خادمياً من signature/iss/aud/exp/sub، ووثّق token TTL/rotation/reuse/revocation ونطاق token المحدود. وثّق body الجهاز ومعنى X-Device-Id وأي device proof بدلاً من اعتبار ID قابل للتزوير تفويضاً.

سلّم قائمة session-state الفعلية وشروط الانتقال للتسجيل/اختيار الاستخدام/البيانات الأساسية والأكاديمية/قبول الشروط/طلب نقل الجهاز وانتظاره/الحساب الموقوف/تأكيد الفصل/دخول الرئيسية. وثّق atomic binding لجهاز واحد والتجديد المتزامن والخروج وفقد الجلسة/إعادة التثبيت. القبول: اختبارات token مرفوض/منتهي وaud خاطئ وrefresh معاد/ملغى وحساب موقوف وجهاز غير صالح وتزامن ربط جهازين، وعزل حسابين. المخرج منشور ومطابق للعقد مع بيئة اختبار آمنة؛ سلّمه قبل انتظار بقية الأقسام.
