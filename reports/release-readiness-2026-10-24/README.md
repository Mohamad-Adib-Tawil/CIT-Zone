## ما أُنجز وما يثبته الدليل

1. بنية التطبيق والنقل والحقن وحراسة debug موجودة في `lib/app/` و`lib/core/network/`. `AppDependencies.createStudentPreviewCubit` ما زال ينشئ `DemoStudentRepository` تحت حارس debug؛ لا repository طالب حي.
2. `GoogleSignInGateway` يتحقق من وجود ID token ويعيد هوية للعرض، ولا يبادل الرمز بجلسة Hasobjy. `AppRouter` يوجّه بعد Google إلى صفحة الهوية؛ لذلك استبدال الرئيسية المؤقتة لم يكتمل وظيفياً.
3. بوابة `app_status` تعمل فوق عقد الإعدادات العام بتحميل وصيانة وتحديث وإعادة محاولة/استئناف. تفاصيل دليل 22 أكتوبر في [التقرير](../app-status-2026-10-22/README.md). استجابة الخدمة اليوم لا توفر قرار التحديث المفرد وروابط المتاجر؛ لا يغلق ذلك مهمة Backend.
4. تقرير [شريحة الطالب](../student-features-2026-10-22/README.md) يوثق C09/S05/G03/F07 وCubit الاختيار و8 مقارنات/42 لقطة محاكي. معاينات 48 شاشة/96 مرجعاً لا تعني حفظ تقييم أو قياس وقت أو ملف كشف أو شراء فعلي. لا أعيد اعتماد المطابقة البصرية دون مقارنة حديثة.
5. شغّلت اليوم FVM 3.47.2: `flutter pub get --enforce-lockfile`، `dart format --output=none --set-exit-if-changed lib test` (137 ملفاً، لا تغيير)، `flutter analyze` بلا ملاحظات، و`flutter test --reporter compact`: **543 اختباراً ناجحاً**. السجل [flutter-test.log](flutter-test.log). لم يعد بناء أو تثبيت أو اختبار OAuth/FCM/DRM فعلي في هذه الجولة.

## ما بقي ومن ينجزه

قرئت مهمة الواجهات الحية كاملة في24 أكتوبر: تشمل بطاقة «وقتي» في S02 والتتبع الدوري، لا مجرد شاشة S05؛ لم يثبت تنفيذهما. كما تنص على سنة من الشراء للكورس المستقل؛ لا تعمم على المواد. نُقل ذلك إلى P4 دون تغيير سياسة خادمية من العميل.

- **Backend / Mokhmaljy:** auth/session/device DTOs واختبارات الرفض، بقية عقود Student API وخدماتها، FCM token lifecycle والإرسال، إصدار وروابط تحديث، حقوق الدفع والوسائط/DRM والبيانات الرسمية. الطلب ضمن مهمة العقد القائمة؛ لا يتولاه Flutter بالتخمين.
- **Flutter / Tawil:** session exchange/storage/refresh والتوجيه، الرئيسية والكتالوج والملف/الأكاديمي الحقيقي، ربط التقييم والوقت والعلامات/الكشف والاشتراكات والدفع والتمارين والدعم والإعلانات، FCM ومنصاته، تشغيل/تنزيل محمي بعد إثبات المزود، وحالات الرفض والفراغ والتحميل والمقارنات الحديثة.
- **مالك الحسابات/المنتج:** APNs وحساب Apple وتوقيع المتاجر وupload key/Play certificates، حسم سياسات المنتج المتبقية وDRM والدفع والمحتوى القانوني وروابط المتاجر وتوفير أجهزة قبول. أسرار الحسابات لا توضع في Notion/Git.
- **قبول مشترك:** بيانات اختبار وعقود حية، أجهزة قديمة/ضعيفة، accessibility وRTL ولوحة المفاتيح والأداء، AAB/IPA موقعة وinternal testing/TestFlight ثم تحقق الرحلات من الحزمة الموزعة وإقرار النشر.
