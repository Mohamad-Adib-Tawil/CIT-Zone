# بوابة إعدادات تطبيق الطالب — 2026-10-22

المسؤول: Mohamad Adib Tawil مع Codex. أصل التصميم والتحليل لمسار Mohammad Mokhmaljy مع Claude؛ هذه مساهمة تنفيذ Flutter ومراجعة العقد المنشور. لا Backend أو Dashboard أو SQL في هذه الدفعة.

## المنفذ

- خدمة Hasobjy المعتمدة افتراضياً: `https://hasobjy-system-api.vercel.app/api/v1/`، قابلة للتجاوز بالتهيئة الصريحة.
- طلب إعدادات فعلي مع نسخة التطبيق المثبتة والمنصة، ومحول صارم لـdata/maintenance/platforms، ومقارنة إصدار رقمية؛ لا قيمة افتراضية لقرار الخدمة عند الفشل.
- بوابة بداية واستئناف تحجب متابعة الدخول عند التحميل أو الخطأ أو الصيانة أو الحد الأدنى غير المدعوم. غياب API في production/staging لا يتجاوزها. تطوير بلا API يبقى متاحاً للمعاينات المعزولة.
- Android PackageInfo وiOS Bundle عبر MethodChannel؛ فتح روابط HTTPS للمتجر المناسب، مع فشل واضح إذا كان الرابط غير متاح. لا تبعيات جديدة أو رفع حد النظام.
- ترويسات إضافية خلف ApiClient، مع منع حقن control characters وتجاوز Host أو Request-ID قبل الاتصال؛ اختبارات مشتركة لمحولي Dio/Io.
- مكونات وخطوط وأصول Figma المحلية وARB. نسخ I-01..05 الداكنة والفاتحة لها سياقات ولقطات مرجعية حديثة في `figma/` وجرد في `frames.json`.

## التحقق والأدلة

- `flutter pub get --enforce-lockfile`: نجح؛ لا تعديل lockfile.
- suite الكاملة النهائية: 502 اختبار ناجح، وتشمل اختبار الحجب عند غياب API في الإنتاج. إعادة الفحوص المستهدفة جزء منها وليست اختبارات إضافية عند حساب المجموع.
- `flutter analyze`: بلا ملاحظات؛ `dart format --output=none --set-exit-if-changed lib test` ناجح؛ `git diff --check` ناجح.
- Android debug ARM32/ARM64: بني بنجاح. لا جهاز Android متصل في هذه الجلسة؛ لا ادعاء تشغيل عليه.
- iOS simulator: بني وثبت وشغل على iPhone Duo / iOS 27.1. اختبر `appInfo` الأصلي وعقد GET app/config الحي دون مصادقة أو كتابة، وقرأ الإصدار `1.0.0`.
- اختبارا التكامل المكتوبان ناجحان؛ عداد runner يعرض 3 مع teardown المولد. التقطت 30 صورة: خمس حالات × نمطان × عروض 320/390/600. عرض 320 يفحص text scale 1.5؛ البقية 1.0. تقرير البيئة في `device-run.json` والصور في `device-320/`, `device-390/`, `device-600/`.
- أمثلة مقارنة جانبية: `I-04-pair.png`, `I-04-LIGHT-pair.png`, `I-01-pair.png`, `I-03-pair.png`. راجعت محاذاة الرسائل والأصول والأزرار في هذه الأمثلة. كل أصل مستخدم له ملف SVG غير فارغ بجذر صالح؛ أصلحت ملفات تنزيل فارغة كشفتها تجربة التكامل قبل إعادة الفحص الناجحة.

## الحدود والفروق المتبقية

- الخلفيات SVG الأصلية تُظهر اختلاف تنعيم/تدرج نقطي في Flutter مقارنة بتصيير Figma؛ الأدلة لا تدعي تطابقاً بكسلياً كاملاً. زوايا الإطار وشريط Figma للتصوير المرجعي فقط؛ التطبيق الطبيعي يستعمل SafeArea وشريط النظام.
- لا انتقال إلى تنزيلات أو دعم تجريبيين من بوابة الإنتاج، ولا نص يعد بحفظ تقدم أوفلاين غير منفذ. زرّا Figma الثانويان لتلك الشرائح غير مفعلين هنا؛ هذا فرق وظيفي ظاهر ومعلن يمنع قبول الشريحة كتطبيق نهائي مطابق حتى اكتمالهما أو اعتماد استثناء.
- رابطا المتجر في الخدمة null. أحدث إصدار وقرار تحديث خادمي صريح غير موجودين في العقد المنشور الحالي؛ مهمة Backend الجديدة تشير إلى مهمة سياسة الإصدار القائمة لمعالجة ذلك. منع minVersion في العميل لا يعوض فرض السياسة على الخادم.
- GoogleIdentity لا يزال هوية Google دون جلسة Hasobjy. DTOs للمصادقة/session-state/البيانات المحمية لم تُختلق؛ طلبت من مسار Backend بمهمة Notion بناء على توجيه صاحب المشروع.
- مهمة Backend: https://app.notion.com/p/401921ef52a98069924adeeea40a446a . أُنشئت في مساحة Hasobjy وعينت إلى Mohammad Mokhmaljy بحالة TODO؛ قرئ محتواها والتعيين في تبويب مستقل. واجه المتصفح بعد ذلك خللاً في العرض مع بقاء AX؛ ظهرت لاحقة B في عنوان الصفحة وفق القراءة المستقلة ومحاولات تصحيح العنوان أضافت سطرين مكررين من العنوان إلى آخر النص. لم تمسح المتطلبات أو تنشئ مهمة أخرى. هذه ملاحظة تنسيق في المهمة، وليست تغييراً في نطاقها أو دليل تسليم Backend. لم تتوفر لقطة مرئية صالحة لتوثيق صفحة Notion بعد خلل العرض.
- لا تحقق صلاحيات طالب حي، أو شراء أو FCM أو DRM أو أوفلاين محمي أو جهاز منخفض الذاكرة أو iOS 15/Android API24 فعليين. لا AAB/IPA نشر موقعان أو رفع للمتاجر.
- امتلأ القرص أثناء نسخ بناء iOS الأول؛ حذفت النسخة الجزئية المتولدة بهذه المحاولة فقط، وأوقفت المحاكي الذي شغلته ثم أعدته عند الحاجة، ونجح البناء اللاحق. لم تنظف Gradle أو CoreSimulator أو DerivedData أو ملفات المستخدم.

النتيجة: شريحة إعدادات Flutter متصلة ومختبرة؛ تطبيق الطالب الكامل ما زال غير جاهز للنشر.
