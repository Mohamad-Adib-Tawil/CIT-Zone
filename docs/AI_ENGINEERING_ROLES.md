# أدوار المساعد البرمجي في Hasobjy

اعتماد النطاق: 2026-10-26 بطلب صاحب المشروع تنفيذ خطة البنية. هذه مسؤوليات ومراحل مراجعة يمكن للمساعد نفسه أداؤها بالتتابع، وليست تفويضاً لتشغيل وكلاء إضافيين أو إرسال رسائل أو تعديل تكليف الفريق.

## 1. المعماري

- المدخلات: AGENTS وخطة الميزة والقرارات وأحدث تسليم متاح وحالة Git والعقود الفعلية.
- يحدد سلوك المستخدم وحالات الرفض والنجاح وحدود الطبقات وملكية الموارد وأثر المنصات والبيانات.
- المخرج قبل الكود: بطاقة تنفيذ، ملفات متأثرة، قرارات مانعة، خطة ترحيل واختبارات ومعيار قبول.
- يطبق SOLID عملياً: مسؤولية واضحة، تركيب بدلاً من توريث شكلي، عقود ضيقة، تبديل التنفيذ دون تغيير السلوك، وحقن الاعتماديات. لا BaseRepository/BaseCubit عام بلا استعمال واضح، ولا use case يمرر استدعاءً فقط.

## 2. منفذ Flutter

- ينفذ شريحة رأسية محددة بـconstructor injection وCubit افتراضياً؛ Bloc عند الحاجة إلى سياسة أحداث واضحة.
- يحتفظ بـdomain نقياً وDTO في data؛ `Either<Failure, Value>` موحد من core/errors/either.dart.
- ApiClient هو عقد النقل وApiFailure خطأ نقل، وتحويله إلى فشل الميزة داخل data؛ الواجهة لا تمسك Dio/JSON أو أسراراً أو تفويضاً محلياً.
- ينشئ GetIt داخل app/di فقط وGoRouter داخل app/router فقط؛ الواجهات تستقبل callbacks عند التنقل خارج مسؤوليتها.
- يحفظ عمل المستخدم والتغييرات المتزامنة؛ لا reset/stash شامل أو إعادة تنسيق واسعة أو نسخ Demo إلى إنتاج.
- المخرج: فرق محدود، تكامل كامل للشريحة، واختبارات وذكر الباقي دون ادعاء النشر.

## 3. مراجع API والأمن

- يراجع مطابقة العقود والتفويض من الخادم، انقضاء الجلسة وتبديل الحساب، وعدم تسريب الرموز والروابط/رسائل الاستثناءات.
- يختبر 401/403/409/422/429 والشبكة والمهلة والإلغاء والرد المشوه بحسب الميزة.
- لا retry تلقائياً لعملية كتابة أو refresh/token exchange مخترع، ولا cache يمنح استحقاقاً، ولا تخفيض DRM.
- لا يختار تقنية Backend أو يعدّل SQL أو مهمة مسار آخر بالاستنتاج؛ يحدد الدليل الناقص ويواصل المستقل.
- المخرج: ملاحظات قابلة لإعادة الإنتاج حسب الخطورة، أو نتيجة مراجعة محددة النطاق؛ لا ضمان أمني شامل.

## 4. مراجع الجودة والأداء

- يشغل FVM وlockfile المقفل وحدود AST والتحليل والاختبارات والتوليد الحتمي عند تأثره.
- يختبر السباقات والنقر المتكرر والإغلاق والنتائج المتأخرة واستعادة الخطأ؛ اختبارات النتائج الحالية ترحّل دون تخفيف معيارها.
- يحافظ على API24/iOS15 والتحميل الكسول وإغلاق الموارد، ويقارن الأداء على الجهاز نفسه وفق الخطة14.
- التغيير المرئي يحتاج إطار Figma فعلي وصورة مقارنة؛ نجاح Widget أو build ليس مطابقة بصرية أو دليل DRM أو أداء جهاز ضعيف.
- المخرج: أوامر ونتائج وبيئة تحقق مؤرخة، ملفات دليل، والمخاطر والفحوص غير المنفذة.
