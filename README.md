## البنية والأجهزة المستهدفة — 2026-10-16

البنية المعتمدة للتوسع: Feature-first + Clean Architecture + Cubit، تطبيق طالب Flutter ولوحة ويب إدارية مستقلة وخادم API خاص مقسم إلى وحدات. [الأساس الهندسي](plans/12-engineering-foundation.md) يشرح حدود المسؤوليات وترتيب الترحيل؛ [سجل الحزم](plans/13-packages.md) يحدد ما أضيف فعلياً وموضع استعماله وما لم يُفعّل بعد.

الهواتف الضعيفة والقديمة متطلب أساسي وفق [خطة التوافق والأداء](plans/14-low-end-devices.md): Android 7 / API 24 فأحدث، وiOS 15 فأحدث حالياً، مع اختبار أجهزة 2GB وARM32/ARM64 حسب المكتبات. لا يثبت هذا وحده دعم DRM؛ يلزم اختبار قدرات الجهاز والرخصة. [خطة الوسائط](plans/05-media-offline.md) تغطي Widevine/FairPlay والتنزيل المرخص وPDF وسياسة الإبطال. الميزانيات أهداف قياس، وليست نتائج اختبارات منجزة.

أضيفت تبعيات التوجيه والشبكة وDrift والتخزين الآمن والنماذج وPDF وأدوات الاختبار والتوليد. مسارات العرض وعميل الشبكة القائمان لم يُستبدلا تلقائياً، ولم يُنفذ خادم أو DRM أو تنزيل بتثبيت الحزم. قواعد المهندس الدائمة في [AGENTS](AGENTS.md) و[قاعدة البنية](.cursor/rules/hasobjy-engineering.mdc).

[تقرير التحقق المؤرخ](plans/implementation/2026-10-16-engineering-foundation.md): التحليل والاختبارات الـ62 ناجحة، وبناء Android ARM32/ARM64 وiOS Simulator ناجح؛ اختبارات الأداء وDRM على الأجهزة الحقيقية ما زالت مطلوبة.

منصة تعليمية مستقلة لطلاب المعهد التقني للحاسوب في حلب. نُفذت معاينتا الطالب والإدارة داخل Flutter، مع تجهيز اختيار حساب Google من جهة العميل؛ بقية الخدمات والخادم لم تُنفذ بعد.

متطلبات مساحة Hasobjy في Notion محفوظة محلياً في [فهرس المصادر](docs/notion/README.md)، وموزعة على [خطة القصص الكاملة](plans/10-notion-requirements.md) وقواعد المشروع وخطط الميزات. توجد [سكيما PostgreSQL محلية](database/README.md) مع مصدرها الخام والتعديلات و[مخططات ERD](database/erd/README.md) و[قاموس البيانات](database/data-dictionary.md). هذه أصول تصميم موثقة ومختبرة محلياً، وليست قاعدة إنتاج متصلة بالتطبيق.

ابدأ من [فهرس الخطط](plans/README.md) لفهم النطاق والمعمارية والأمن ومراحل التنفيذ، واقرأ [قواعد العمل للمساعدين البرمجيين](AGENTS.md) قبل تعديل الكود.

أي عمل على الواجهات ملزم بـ[عقد مطابقة Figma والخطط والبيانات](plans/11-design-implementation-contract.md). تُحمّل [قاعدة المشروع الدائمة](.cursor/rules/hasobjy-design-contract.mdc) للتذكير به؛ يلزم إطار فعلي عبر MCP، وتتبع السلوك إلى الخطة والبيانات، ومقارنة صور التطبيق قبل قبول الواجهة.

نسخة Flutter المضبوطة في `.fvmrc` هي `3.47.2`. قرارات المنهج والاشتراك ومزود الفيديو والتنزيل المحمي معلقة في [سجل القرارات](plans/09-decisions.md).

شغّل `fvm flutter run` لمراجعة شاشة الاستقبال ومعاينتي الطالب والإدارة في وضع التطوير. بيانات المعاينتين تجريبية، ولا تُحفظ المدخلات أو تُنفذ الإجراءات. معاينة الإدارة الحالية مرجع تطوير؛ لوحة الإنتاج المعتمدة في 2026-10-08 تطبيق ويب مستقل متجاوب لم يُنفذ بعد. نسخة الإنتاج لا تعرض المعاينتين. تفاصيل المنفذ والمتبقي في [حالة تنفيذ اللوحة](plans/admin-dashboard/05-implementation-status.md) و[إعداد Google OAuth](plans/implementation/google-oauth-setup.md).

[حالة التنفيذ الكاملة قبل الخادم](plans/implementation/2026-09-26-pre-backend-status.md) توضّح ما يمكن تجربته الآن وما يحتاج بيانات المعهد وخادم API.

أُضيف [أساس اتصال API](plans/implementation/2026-09-26-api-foundation.md) دون ربط endpoint إنتاجي. يُقرأ `APP_ENV` (`development` أو `staging` أو `production`) و`API_BASE_URL` عبر `--dart-define` حين يتوفر الخادم؛ يتطلب الاتصال الخارجي HTTPS، ويسمح عنوان HTTP محلي في التطوير لاختبارات النقل فقط. لا يؤدي تمرير العنوان وحده إلى تسجيل دخول أو إظهار بيانات حقيقية.

يتطلب Android release [مفتاح رفع خاصاً وإعداداً محلياً](plans/implementation/2026-09-26-android-release-signing.md)؛ لم يعد يُوقّع بمفتاح debug.

المواصفات الجديدة المعتمدة في [خطة المنتج](plans/01-product.md) و[سجل القرارات](plans/09-decisions.md) تشمل PDF مجاني، اشتراكات مادة/فصل، دفع مشروط، تمارين وإشعارات ودعم، وعلامات OCR مراجَعة من لوحة الويب. راجع [دراسة النظام](plans/00-system-study.md) للملخص؛ هذه مواصفات وليست ميزات مكتملة.
